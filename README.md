# AWS Student Community Day

A modern, responsive frontend website designed for AWS Student
Community Day, focused on student learning, collaboration,
community engagement, and events.

## Live Demo
https://aws-student-community-day-two.vercel.app/g

## Features

- Responsive React-based interface
- AWS-inspired visual design
- Event discovery and event details
- Community information and participation sections
- Interactive navigation
- Modern blue, white, and yellow color palette

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Design Approach

The design uses a balanced AWS-inspired color palette,
clear visual hierarchy, responsive layouts, and
community-focused imagery.

## Getting Started

npm install
npm run dev
